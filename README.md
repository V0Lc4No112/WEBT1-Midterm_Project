# Space Notes - Midterm Project

Mereikhan Sholanbayev, IT-2511 (individual project)

A short guide to the six Apollo Moon landings for students.

- Repository: https://github.com/V0Lc4No112/WEBT1-Midterm_Project
- Website: https://v0lc4no112.github.io/WEBT1-Midterm_Project/

## Pages

- `index.html` - Home: hero with a simple CSS Moon, numbers strip, Apollo 11, spacecraft cards.
- `missions.html` - Missions: the six landings (own CSS Grid), a note about Apollo 13, mission data table.
- `ask.html` - Ask: question form and an accordion with common questions.
- `css/style.css` - the only stylesheet, shared by all pages.

## Course topics

- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `ol`, `table` with `caption`, `thead`, `tbody`, `tfoot`, `th scope`.
- Form: `ask.html`, native validation (`required`, `type="email"`, `minlength`), `fieldset` and `legend` for the radio group.
- Table: `missions.html`, two columns are hidden on phones with `d-none d-sm-table-cell`.
- Flexbox: numbers strip and footer.
- Grid: the six landings list (1, 2 and 3 columns).
- Own media queries: 768px and 992px.
- Bootstrap 5.3: navbar, grid, cards, buttons, form controls, table, accordion. Colors are changed with Bootstrap CSS variables.
